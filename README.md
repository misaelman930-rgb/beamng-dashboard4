# BeamNG Radio

Интернет-радио и плеер для Windows 10/11, который подключается к BeamNG.drive по протоколу **OutGauge (UDP)** и меняет звук в зависимости от того, что происходит в игре.

## Стек и почему

**Python 3.11+ · PySide6 · python-vlc (libvlc) · pynput**

| Выбор | Причина |
|---|---|
| Python + PySide6 | Один язык для UDP, правил и UI; зрелый Qt с прозрачными окнами для оверлея. Сборка в один `.exe` через PyInstaller. |
| python-vlc | Из коробки: Icecast/Shoutcast, mp3/aac/ogg/flac/wav, ICY-метаданные, выбор устройства вывода, 10-полосный эквалайзер (на нём «радио в машине»). |
| pynput | Глобальные хоткеи без прав администратора. |
| Не Electron | Electron + аудио-библиотеки тяжелее по RAM/CPU, а игре нужны ресурсы. Здесь UI обновляется ~5 раз/с, логика — 10 раз/с. |

Нагрузка: UDP-поток только запоминает последний пакет, вся логика идёт в таймере 10 Гц, VLC дёргается только при изменении значений.

## Архитектура

```
main.py                    точка входа
radio/
  telemetry.py             OutGauge: парсер пакета + UDP-поток с автопереподключением
  beamngpy_module.py       (опц.) альтернативный источник телеметрии через BeamNGpy
  rules.py                 движок правил «если → то» + интерполяция кривой громкости
  audio.py                 VLC: потоки, файлы, ICY, эквалайзер, устройства, ретраи
  stations.py              стартовые станции, избранное, поиск в radio-browser
  settings.py              JSON-настройки (%APPDATA%\BeamNGRadio\settings.json)
  hotkeys.py               глобальные горячие клавиши
  i18n.py                  RU/EN
  controller.py            связывает всё; главный тик 10 Гц
  ui/                      main_window, overlay, dialogs, styles (QSS)
tools/outgauge_emulator.py эмулятор игры
tests/test_core.py         тесты ядра (без Qt/VLC)
```

Поток данных: `UDP → TelemetryListener.last → Controller._on_tick → RuleEngine → громкость / пауза / фильтр / действия → AudioEngine`.

## 1. Включить OutGauge в BeamNG.drive

1. Запустите BeamNG.drive.
2. **Опции → Другое (Other) → Протоколы (Protocols)** (в некоторых версиях — Options → Misc → Protocols / «Прочее»).
3. Включите **OutGauge**.
4. IP: `127.0.0.1`, порт: `4444` (или свой — тот же порт укажите в *Настройки → UDP-порт*).
5. Частота — можно оставить по умолчанию.
6. Поедьте на любую карту: в приложении индикатор сменится на «Подключено к BeamNG».

Если индикатор не загорается: проверьте, что порты совпадают, что брандмауэр не блокирует Python/exe (для 127.0.0.1 обычно не мешает), и что порт не занят другой программой (индикатор станет красным).

## 2. Запуск из исходников

1. Установите **Python 3.11+** (64-бит).
2. Установите **VLC media player 64-бит** с videolan.org (нужна разрядность, совпадающая с Python).
3. В папке проекта:
   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python main.py
   ```

## 3. Проверка без игры (эмулятор)

В другом окне терминала:

```bat
python tools\outgauge_emulator.py                 :: сценарий «поездка» (60 с по кругу)
python tools\outgauge_emulator.py --scenario highway
python tools\outgauge_emulator.py --interactive   :: ручные команды: s120, r4000, l, p, a, t, h, e, q
python tools\outgauge_emulator.py --drop 0.3      :: имитация потерь пакетов
```

Сценарий «drive»: стоим → разгон → правый поворотник → трасса (дальний, TC) → торможение с ABS → ручник → мотор заглушён → снова завели. Так можно проверить громкость от скорости, приглушение на поворотнике/ABS, автопаузу, смену жанра и эффект фильтра.

Тесты ядра: `python -m unittest discover -s tests -v`

## 4. Сборка .exe

```bat
build.bat
```
или вручную:
```bat
pyinstaller --noconfirm --windowed --name BeamNGRadio --collect-submodules pynput main.py
```
Результат: `dist\BeamNGRadio\BeamNGRadio.exe`. На целевом ПК должен быть установлен VLC (приложение найдёт его в `Program Files\VideoLAN\VLC`; другой путь — переменная окружения `VLC_PATH`). Если нужен автономный дистрибутив, скопируйте `libvlc.dll`, `libvlccore.dll` и папку `plugins` из VLC рядом с exe и задайте `VLC_PATH` на эту папку.

## 5. Использование

- **Станции**: двойной клик — играть; «＋» — добавить по URL (mp3/aac/ogg, `.pls`, `.m3u`); ★ — избранное; «Локальные файлы…» — очередь mp3/flac/wav; «Найти онлайн…» — поиск в каталоге radio-browser.info.
- **Стартовые станции**: рок, электроника, retro, jazz, news — прямые ссылки (Radio Paradise, SomaFM, BBC World Service). Для **phonk** и дополнительных «авто-подбор» станций URL берётся из каталога radio-browser.info при первом запуске (прямые ссылки на phonk-станции быстро устаревают). Мёртвая станция пропускается автоматически.
- **Запуск BeamNG**: кнопка «Запустить BeamNG» в шапке. Ищет exe по типичным путям Steam/Epic или запускает через `steam://rungameid/284160`. Свой путь — в *Настройки → Путь к BeamNG.drive.exe*.
- **Оверлей при запуске двигателя**: когда в игре заводится мотор (OutGauge `engine_off` → off), автоматически показывается оверлей и (если включено) стартует последняя станция. Настройка — «Оверлей при запуске двигателя» в Общих.
- **Горячие клавиши** (по умолчанию): `Ctrl+Alt+P` пауза, `Ctrl+Alt+←/→` станции, `Ctrl+Alt+↑/↓` громкость, `Ctrl+Alt+M` mute, `Ctrl+Alt+O` оверлей, `Ctrl+Alt+T` click-through. Меняются в *Настройки → Горячие клавиши* (формат pynput: `<ctrl>+<alt>+p`).
- **Оверлей**: современный Now Playing (обложка, трек, транспорт). Перетаскивается мышью; `Ctrl+Alt+T` включает click-through (клики идут в игру). Виден только если BeamNG запущена в режиме **«Окно без рамки / Borderless»** — поверх эксклюзивного полноэкранного режима Windows ничего не рисует.
- **Правила**: кнопка «Правила». Формат: *если [переменная] [оператор] [значение] (держится N с) → [действие]*. `while` — действует, пока условие истинно; `once` — один раз по фронту (с паузой cooldown). Действия: `duck` (приглушить, параметр 0..1), `pause`, `mute`, `filter` (сила 0..1), `next`, `prev`, `genre` (параметр — жанр), `jingle` (путь к файлу или пусто — встроенный сигнал), `set_volume`.
  Переменные: `speed_kmh, rpm, gear, fuel, engine_temp, oil_temp, turbo, throttle, brake, clutch, handbrake, signal_left, signal_right, signal_any, fullbeam, abs, tc, oil_warn, battery_warn, shift_light, engine_off, stopped`.
- **Громкость от скорости**: кривая «км/ч → %» в *Настройки → Эффекты*. Итоговая громкость = ползунок × кривая × приглушения правил.
- **«Радио в машине»**: срез высоких и низких + подъём середины; сила растёт с оборотами.
- **Автосмена жанра**: ниже порога — спокойный жанр, выше — энергичный; не чаще чем раз в N секунд.

## Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Поток недоступен / оборвался | 3 попытки с задержкой 2/4/8 с, затем станция пропускается |
| Зависшая буферизация (>25 с) | считается сбоем, переподключение |
| Игра закрыта/перезапущена | «Ожидание игры», при первом же пакете — снова «Подключено» |
| Битые/короткие UDP-пакеты, NaN | игнорируются; потери считаются по ID пакета |
| Порт занят | красный индикатор, повторная попытка каждые 2 с |
| Смена/отключение аудиоустройства | проверка раз в 5 с, переход на системное и перезапуск потока |
| Битый `settings.json` | сохраняется как `.broken`, запуск с настройками по умолчанию |
| Нет VLC | понятное сообщение, остальное приложение работает |

## BeamNGpy — чем отличается

См. docstring в `radio/beamngpy_module.py`. Коротко: OutGauge — пассивная трансляция из обычной игры, ничего не требует. BeamNGpy — исследовательский API (любые датчики, управление сценариями), рассчитан на **BeamNG.tech** (отдельная лицензия), требует строгого совпадения версий и открытого TCP-порта. Поэтому он вынесен в необязательный модуль и не подключён к UI по умолчанию.

## Идеи для расширения

1. **Мод на Lua внутри игры**: отправлять расширенные данные (повреждения, GPS-координаты, режим трансмиссии, дрифт-угол) тем же UDP на другой порт JSON-ом; в радио добавить второй приёмник и правила по этим переменным («сильный удар → пауза», «дрифт → phonk»).
2. **Голосовой диктор**: вставки TTS (Windows SAPI / edge-tts) между треками — название трека, «топливо на исходе», «ограничение скорости»; на время вставки приглушать музыку правилом `duck`.
3. **Статистика поездок**: писать в SQLite пробег, среднюю/макс. скорость, время в движении, расход топлива, любимые станции по жанру/скорости; экран «Итоги поездки» после остановки игры (событие disconnected).
4. Профили правил под машину (по полю `car` из пакета), синхронизация станций между ПК, управление с телефона через маленький HTTP-сервер.

## Сервер станций (загрузка станций через сайт)

Приложение может подтягивать список станций с вашего сервера. Добавлять и удалять станции можно в браузере, а радио обновит список само (раз в 5 минут).

**Состав:** `server/app.py` — веб-страница `/` и JSON-API `/api/stations`. Только стандартная библиотека Python, без зависимостей.

### Запуск локально
```bat
set ADMIN_TOKEN=придумайте-длинный-секрет
python server\app.py
```
Откройте http://localhost:8000, введите ключ, добавьте станцию (адрес потока `http(s)://…`).

### Деплой на Render
1. Залейте проект в GitHub.
2. Render → **New → Blueprint** → выберите репозиторий (читается `render.yaml`).
3. В Environment скопируйте сгенерированный `ADMIN_TOKEN` — это ключ для страницы.
4. Откройте выданный адрес вида `https://beamng-radio-stations.onrender.com`.

Станции хранятся в файле `DATA_FILE` на постоянном диске (`/var/data`). Постоянный диск на Render доступен только на платных планах, поэтому `render.yaml` использует план `starter`. На бесплатном плане диск эфемерный: список очистится при перезапуске сервиса.

### Подключение приложения
В **Настройки → Общие → Сервер станций (URL)** вставьте адрес сервера. Станции с сервера появятся в списке с обычными станциями и помечаются как удалённые: их можно слушать и добавлять в избранное, но удалить можно только на сайте. Если сервер недоступен, приложение использует сохранённый список.

### API
| Метод | Путь | Что делает | Нужен ключ |
|---|---|---|---|
| GET | `/api/stations` | список станций | нет |
| POST | `/api/stations` | добавить `{"name","url","genre"}` | да (`Authorization: Bearer …`) |
| DELETE | `/api/stations/{id}` | удалить | да |
| GET | `/healthz` | проверка для Render | нет |

Проверка адреса: только `http://` и `https://`, без пробелов, до 500 символов. Сервер сам поток не открывает, поэтому его нельзя использовать для запросов к внутренним адресам.

## Если приложение не запускается

Ошибка записывается в `crash.log` в папке `%APPDATA%\BeamNGRadio` и показывается окном. Частые причины:
- не установлен PySide6 или другие зависимости: `pip install -r requirements.txt` в активированном venv;
- не установлен VLC (нужна 64-битная версия, как и Python). Без VLC приложение запускается, но звук не работает — в строке состояния будет подсказка;
- занят порт UDP 4444 — тогда индикатор «Порт занят», а не падение.

## Шансон, русские радио и «Трасса FM»

- **Шансон**: «Радио Шансон» и два авто-подбора по тегу `chanson`.
- **Русские радио**: «Русское Радио», «Европа Плюс», «Ретро FM», «Радио Рекорд», «DFM» и авто-подбор русских хитов. Адреса подбираются из каталога radio-browser.info по названию, поэтому они всегда актуальные. Если какая-то станция не нашлась, она просто не будет играть (сообщение о недоступности появится в строке состояния).
- **«Трасса FM»** — своё радио. Это ротация: через каждые 15 минут оно переключается на следующую станцию из списка (шансон и русские радио), перед переключением звучит короткий джингл. Длительность меняется полем `rotate_min` в `stations.json`, состав — полем `rotate`.


## Авторадио при запуске двигателя

При получении телеметрии OutGauge приложение автоматически запускает выбранную
(последнюю использованную) радиостанцию при запуске двигателя и показывает
оверлей с выпадающим списком доступных станций и кнопкой «Включить радио».
Можно выбрать другую станцию прямо в оверлее. Функция включена по умолчанию
(`autoplay_on_engine` в `settings.json`).

**Важно:** автоматическое определение запуска двигателя сейчас работает через
OutGauge. Это поддерживает BeamNG.drive при включённом OutGauge. Для City Car
Driving 1 нужен совместимый источник телеметрии/плагин, который отправляет
пакеты OutGauge на настроенный UDP-порт; без такой телеметрии приложение не
может определить запуск двигателя.
